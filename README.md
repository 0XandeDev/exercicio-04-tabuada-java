# Exercício 04 - Tabuada em Java

## Sobre o projeto
Programa desenvolvido em Java que solicita ao usuário um número inteiro e apresenta sua tabuada de 1 a 10.

## Funcionalidades
- Solicita um número inteiro ao usuário.
- Calcula a multiplicação do número pelos valores de 1 a 10.
- Exibe os resultados da tabuada no console.

## Conceitos praticados
- Entrada de dados com Scanner.
- Declaração e utilização de variáveis.
- Estrutura de repetição for.
- Operadores aritméticos.
- Concatenação de textos.
- Lógica de programação.

## Tecnologias utilizadas
- Java
- IntelliJ IDEA

## Objetivo
Praticar estruturas de repetição e operações matemáticas,
desenvolvendo o raciocínio lógico por meio da linguagem Java.
